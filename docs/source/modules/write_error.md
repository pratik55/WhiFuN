# write_error

## Signature

```matlab
function write_error(exception,quality_control_path,name)
```

## Summary

WRITE_ERROR Displays and optionally logs MATLAB exceptions to a file.

## Syntax

```matlab
WRITE_ERROR(exception) catches a MATLAB MException object and cleanly
WRITE_ERROR(exception, quality_control_path, name) performs the
```

## Description

prints the error identifier, message, timestamp, and stack trace (with line numbers) directly to the MATLAB Command Window.

command window display and additionally appends the error details to a text file. The file is saved inside an 'Error_Info' folder within the provided quality_control_path. The text file is named using the format: '<name>_error_info.txt'. If the target directory does not exist, the function creates it automatically.

## Input Arguments

### `exception`
MATLAB MException object generated by a try/catch block.

### `quality_control_path`
(Optional) String or char array specifying the base directory where the 'Error_Info' folder should be located/created.

### `name`
(Optional) String or char array representing the subject name or run identifier. Used for the text file naming and logged inside the file.

## Examples

Example: try % some code that fails error('MyCode:BadInput', 'Invalid input detected.'); catch ME end

```matlab
write_error(ME, 'C:\Data\QC', 'Subject_01');
```
